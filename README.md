# G-ONE ResQ — Emergency First-Aid Voice Companion MVP

G-ONE ResQ is a voice-driven emergency companion designed to guide callers through first-aid crises in **English**, **Hindi**, and **Hinglish**.

## Safety Guarantee
- **Never diagnoses disease.**
- **Never prescribes drug dosages.**
- **Strict Protocol Enforcement:** Responses are validated against structured clinical protocols.
- **Provider Fallback Engine:** If Google Gemini or Groq quotas are exceeded, it automatically transitions to the safe deterministic responder without crashing.
